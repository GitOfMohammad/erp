# ماژول‌های تکمیلی ERP

این مرحله ماژول‌های تولید، دارایی ثابت، بودجه، پروژه و زنجیره تأمین را با مدل، مایگریشن، اعتبارسنجی، کنترل دسترسی و مسیرهای Swagger اضافه می‌کند.

## راه‌اندازی

1. npm run db:migrate
2. npm run db:seed:permissions

مایگریشن جدید هنوز روی دیتابیس اجرا نشده است. مسیرها زیر پیشوند API تنظیم‌شده در env (معمولاً /api/v1) قرار دارند:

- تولید: /production/boms, /production/bom-items, /production/orders, /production/quality-checks
- دارایی ثابت: /financial/assets/register, /financial/assets/register/{id}/depreciate
- بودجه: /financial/budgets/budgets, /financial/budgets/budget-lines, /financial/budgets/budgets/{id}/variance
- پروژه: /projects/projects, /projects/tasks, /projects/expenses
- SCM: /scm/shipments, /scm/shipment-items, /scm/vendor-updates

## قواعد اجراشده

- BOM فقط وقتی فعال می‌شود که حداقل یک ماده اولیه داشته باشد. مواد فقط در BOM پیش‌نویس قابل تغییرند.
- آزادسازی دستور تولید مواد را از انبار انتخاب‌شده مصرف می‌کند؛ خروجی زیر صفر نمی‌رود. ارزش مواد با میانگین موزون همان انبار به کار در جریان ساخت منتقل می‌شود.
- تکمیل دستور تولید پس از ثبت کنترل کیفیت کل مقدار برنامه‌ریزی‌شده انجام می‌شود. محصول سالم وارد موجودی می‌شود؛ بهای بخش مردود به حساب ضایعات تولید می‌رود. هزینه مواد با میانگین موزون محاسبه می‌شود و دستمزد و سربار مستقیم هر دستور در کار در جریان ساخت ثبت و هنگام تکمیل به بهای محصول سالم/ضایعات تخصیص می‌یابد. دستمزد مستقیم به «حقوق پرداختنی» و سربار به «حساب‌های پرداختنی تجاری» بستانکار می‌شود.
- استهلاک دارایی خط مستقیم ماهانه است، ارزش اسقاط و عمر مفید را لحاظ می‌کند، دوره‌ها باید پیوسته باشند و هر دوره سند متوازن دفتر کل می‌سازد.
- ردیف بودجه فقط در پیش‌نویس قابل تغییر است؛ ماه‌ها باید در بازه بودجه باشند. گزارش انحراف فقط برای بودجه تأییدشده، از اسناد قطعی دفتر کل محاسبه می‌شود.
- پروژه تا پایان وظایف فعال قابل تکمیل نیست. هزینه تأییدشده از سقف بودجه غیرصفر پروژه عبور نمی‌کند.
- جهت مرسوله باید با نوع طرف حساب و سند بازرگانی تأییدشده سازگار باشد. اقلام پس از ارسال قابل تغییر نیستند.

## محدوده نسخه اول

دستمزد و سربار غیرمستقیمِ مشترک بین چند دستور تولید به‌صورت خودکار سرشکن نمی‌شود و باید هزینهٔ مستقیم هر دستور جداگانه ثبت شود. ثبت واگذاری/اسقاط دارایی و بهای خرید اولیه دارایی هنوز به دفتر کل متصل نیست. تأیید هزینه پروژه سند حسابداری یا پرداخت ایجاد نمی‌کند. تغییر وضعیت مرسوله موجودی را تغییر نمی‌دهد، چون اثر موجودی فاکتور تأییدشده را ماژول بازرگانی مدیریت می‌کند. اتصال خودکار SCM به سامانه حمل یا پرتال تأمین‌کننده وجود ندارد.
