# Frontend راهکار ERP

رابط کاربری ERP با React JavaScript و Vite ساخته شده است.

## راه‌اندازی محلی

1. بک‌اند و MySQL را اجرا کنید.
2. در این پوشه `npm install` را اجرا کنید.
3. مقدار `VITE_API_URL` را در `.env.local` قرار دهید (پیش‌فرض: `http://localhost:3000/api/v1`).
4. `npm run dev` را اجرا کنید و آدرس نمایش‌داده‌شده را باز کنید.

## ساخت نسخه انتشار

`npm run build` خروجی را در `dist/` تولید می‌کند. برنامه به‌صورت PWA نصب‌پذیر است. کش آفلاین محدود به فایل‌های ثابت و پوسته برنامه است؛ درخواست‌ها و اطلاعات خصوصی ERP کش نمی‌شوند.

## State management

- Redux Toolkit: نشست، کاربر جاری و دسترسی‌ها.
- TanStack Query: داده‌های API، کش و تازه‌سازی فهرست‌ها.
- وضعیت صفحه و فرم‌ها: محلی با React Hook Form.
- تم: hook سبک همراه localStorage.

اعتبارسنجی ورودی فرم‌ها با Joi در کلاینت انجام می‌شود و اعتبارسنجی بک‌اند همچنان مرجع نهایی است.
